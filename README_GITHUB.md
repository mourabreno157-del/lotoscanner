# Analisador de Jogos — APK

## Publicar no GitHub

1. Crie um repositório novo no GitHub.
2. Envie todos os arquivos deste projeto para a raiz do repositório.
3. Faça o commit na branch `main`.
4. Abra a aba **Actions**.
5. Selecione **Build APK**.
6. Execute **Run workflow**.
7. Ao terminar, abra a execução concluída.
8. Em **Artifacts**, baixe `analisador-jogos-debug-apk`.

## Resultado

O arquivo gerado será:

`app/build/outputs/apk/debug/app-debug.apk`

Ele pode ser instalado manualmente em um Android para teste.
